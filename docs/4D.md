# 4D 시공 시뮬레이션 (S4 · Phase 2)

뷰어 위에 올린 4D 시공 시뮬레이션 1차 기능. 공정 일정(작업: 이름·시작·종료)과
IFC 객체(expressID)를 매핑하고, 타임슬라이더로 현재 시점까지 시공된 객체만 보이게
뷰어 표시를 제어한다.

## 데이터 흐름
```
CSV(Navisworks/Fuzor)
  → schedule.ts (decode + parse)        ScheduleTask[]  (이름·유형·start·end)
  → fourd.ts   (mapByName/mapSequential) TaskMapping     (taskId → [{modelID,expressID}])
  → fourd.ts   (computeStates@now)        Map<el, built|active|future>
  → IfcViewer.applyConstruction(...)      뷰어 표시 제어(숨김/반투명/강조)
```

## 핵심 파일
- `src/lib/schedule.ts` — CSV 파서. **헤더 기반**이라 Navisworks(한글, EUC-KR)와
  Fuzor(영문, UTF-8, ISO 날짜)를 한 파서로 처리. `OutlineNumber` 상위 작업 제외.
- `src/lib/fourd.ts` — 매핑(이름/순서) + 시점별 상태 계산. 한 요소가 여러 작업에
  속하면 `built > active > future` 우선순위. 미매핑 요소는 건드리지 않음(항상 표시).
- `src/viewer/IfcViewer.ts` — `getElementCatalog()`(이름 인덱스),
  `applyConstruction(states, futureMode)`, `clearConstruction()`. 기존
  `setElementVisible` 와 동일한 메시 관리 위에서 동작(공유 재질, 매 틱 복원→재적용).
- `src/components/Timeline.tsx` — 하단 패널: 임포트·4D토글·매핑·재생·슬라이더·간트.
- `src/store/useStore.ts` — `fourd` 슬라이스(일정/현재시점/매핑/모드).

## 매핑 전략 (1차)
1. **이름 매핑(`mapByName`)** — 작업 이름과 IFC 요소 Name 을 정규화해 매칭.
   `"A1 버림: A1 버림"` 처럼 `이름: 별칭` 형태는 양쪽 토큰을 후보로 사용.
2. **순서 자동배정(`mapSequential`)** — 모델 요소를 일정 순서대로 균등 분배. 이름이
   맞지 않는 모델/공정표 조합에서도 시각적으로 동작하는 빠른 데모용(장비·임시 제외).
   이름 매칭이 5% 미만이면 자동으로 이 모드로 폴백.

## 표시 규칙 (시점 `now` 기준)
| 상태 | 조건 | 표시 |
|---|---|---|
| 시공 완료 built | `now ≥ end` | 원래 재질로 표시 |
| 진행 중 active | `start ≤ now < end` | 주황 강조(반투명) |
| 미시공 future | `now < start` | 숨김, 또는 "미시공 반투명" 체크 시 ghost |

## 영속화 (설계만)
- `supabase/migrations/0003_schedule.sql` — `schedules` / `schedule_tasks` /
  `task_elements`(다대다) + `models` 와 동일한 RLS(`is_member`/`is_admin`).
  현재는 **프론트 로컬 상태 + CSV 임포트**로 동작하며, 위 마이그레이션은 추후
  서버 영속화 단계에서 적용한다(추가형·멱등).

## 알려진 한계 / 다음 단계
- **철거(demolish) 의미** 미반영: 현재는 모든 매핑 작업을 "생성"으로 취급. 철거 작업이
  완료되면 해당 객체를 숨기는 처리 필요(`task_elements` + 작업 유형으로 확장).
- 정밀 매핑(동기화 ID/GUID ↔ 요소)은 IFC GlobalId 인덱싱 후 연결(파서가 externalId
  는 이미 보존).
- `applyConstruction` 는 매 틱 전체 상태를 재적용(대형 모델은 증분 갱신으로 최적화 여지).
- 수동 매핑 UI(작업↔선택 객체)·DB 저장/로드는 후속 세션.
