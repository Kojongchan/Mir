## ② 협업·이슈 고도화
- 현재: 이슈 트래커(0007·0012·0013)·3D/도면 핀·상태·담당·알림. 문제: 단순 목록, 타입 구분 없음.
- 고도화(플랫폼 내 완결):
  1) **이슈 타입 분화**: RFI·Punch(하자)·안전·품질·일반 — 타입별 전용 필드·양식·워크플로우·색/아이콘.
  2) **전용 UI(도메인)**: 리스트 + **칸반(상태별)** + **3D/도면 핀 뷰** 3-way 전환. 다 똑같은 표 탈피.
  3) **협의 완결**: 코멘트 스레드(@멘션·읽음)·첨부·3D 뷰포인트/마크업 첨부·기한·담당(관계사/역할 R12)·상태 이력.
  4) **연결**: 이슈↔간섭·이슈↔회의록 액션아이템·이슈↔도면/부재.
  5) **출력/양식**: 이슈 목록 **엑셀 export** + **지적통보서 회사 양식(PDF)** 출력.
  6) **현장**: 모바일 등록·사진(GPS)·오프라인 초안.
- 데이터: issues.type 추가 · issue_comment(issue_id, author, body, mentions jsonb, created_at) ·
  issue_viewpoint(issue_id, camera_state, markup, snapshot). RLS 쓰기=is_editor.
- AC: 타입별 양식·칸반/핀 뷰·스레드/멘션·엑셀+양식 PDF·모바일 등록이 전부 웹에서 동작, 이력 잔존.

## ③ 공정 시뮬레이션 (4D) 고도화
- 현재: APS 위 4D(S50)·속성/이름/순서 매핑·계획대비 빠름늦음 색(0029). 문제: 공정표 입력·실적·공유 약함.
- 고도화:
  1) **공정표 import = 진실원본**: Excel(우선)·MS Project(.xml)·P6(.xer) 파싱 → 작업·기간·선후행·WBS 흡수.
     (엑셀 왕복: import + 현황 export.)
  2) **WBS 트리 + 마일스톤** 뷰, 일정↔객체 매핑 신뢰성(속성 우선), 진행률.
  3) **실적 동기화**: 실제 시작/끝 입력·엑셀 → 계획대비 색(有)·지연 하이라이트.
  4) **4D 워크스루**: 카메라 경로/뷰포인트 순차 재생 + **녹화·공유 링크**(웹에서 열람).
  5) **물량/기성 연동**: 기간별 투입물량·기성 곡선(§0-H·R6).
- 데이터: task/schedule import 매핑, task_elements(0029 有) 확장. RLS 쓰기=is_editor.
- AC: 엑셀/P6 공정표 import → 4D 시뮬·WBS·실적 색·워크스루 공유가 웹에서 완결. 진실원본은 외부 파일, 협의는 플랫폼.

## ④ 자료관리 (CDE/ACC) 고도화  — R4/R5 재사용
- 현재: ACC 파일관리자(0022)·RBAC·리비전. 문제: ISO 19650 승인·자료전송·검색 미흡.
- 고도화(플랫폼 내 완결):
  1) **ISO 19650 승인 워크플로우**: 상태 게이팅(WIP→Shared→Published→Archived) + 승인자 지정 + 감사로그
     (누가·언제·왜). ★서버측 상태전환 검증.
  2) **자료전송(Transmittal)**: 정식 송부 이력·수신확인·표지 자동생성(회사 양식 PDF).
  3) **리비전·이력**(有 보강) + **검색·태그** + 폴더 권한.
  4) **파일관리자 UX**: 트리 폭 리사이즈·이동(move)·새 버전 업로드 **라이브 검증**.
  5) 웹 완결: 미리보기·승인·송부까지 원본 다운로드 없이(모델=APS, 문서=우리 뷰어).
- 데이터: approval_flow(target_type/id, from_state,to_state, approver, decision, comment) · transmittal(+items·수신자·확인)
  · files.status. RLS: 상태전환=승인자 권한, 서버 검증.
- AC: 상태게이팅이 권한대로만·감사로그 기록, 자료전송 송부/수신확인·표지 PDF, 검색·리비전·이동/새버전 동작.

## ⑤ 구성원·권한·역할 고도화  — R12 재사용
- 현재: RBAC 4단계(0023·D20~22). 문제: 회사·다중역할·관계사·역할기반 배정 없음.
- 고도화:
  1) **관계사(협력사·발주처·감리) 마스터 등록**(회사·역할유형·연락처·현장책임자·사업개요 표시 토글).
  2) **구성원 = 회사 + 다중역할(BIM관리자/현장/본사/실무자…) + 접근권한(뷰어/실무자/관리자)** (ACC 참고).
  3) **역할 기반 담당배정 연동**: 이슈·Punch·간섭·결재선이 관계사/역할로 배정.
  4) **초대·계정발급**(프로젝트 관리자 D22), 활동/접속 이력, 엑셀 내보내기.
- 데이터: company(project_id, name, role_type, phone, manager, show_on_overview, active) ·
  project_members.company_id · member_role(member_id, role) 다중. 시스템관리자 보호(D21) 유지.
- AC: 관계사 CRUD·구성원 회사/다중역할/접근권한·역할기반 배정·초대·활동이력이 권한대로 동작.

## ⑥ 사업개요 = 현장 현황판 (War-room) 고도화
- 재정의: 단순 KPI가 아니라 **실제 현장에서 현황판으로 쓰는 화면**.
- 고도화:
  1) **현황판 위젯**: 금일 현장사진(슬라이드)·오늘 이슈·공지·알림·날씨·공정률·안전지표·금일 작업(일보 연동).
  2) **키오스크/대형 디스플레이 모드**: 풀스크린 자동 순환(현장 사무실 벽/모니터).
  3) **Realtime 갱신**(Supabase Realtime) — 이슈/일보/공지 변경 시 즉시 반영.
  4) **프로젝트별 위젯 커스터마이즈**(react-grid-layout, R7) — 철도/도로/단지별 다른 구성.
  5) 모바일 요약 카드.
- 데이터: dashboard_widget(project_id, type, position, config) · notice/announcement · site_photo. RLS 쓰기=is_editor/admin.
- AC: 위젯 현황판·키오스크 모드·실시간 갱신·프로젝트별 커스터마이즈·현장사진 슬라이드가 동작.

## ⑦ 게시판·물량·기성·공정현황 고도화
### ⑦-a 게시판 → 공지·회의록·의사결정 로그 분화 (R2)
- 현재 단순 게시판(40%) → **공지사항 / 회의록·의사결정 로그**로 분화. 회의록: 참석자·본문(마크다운)·결정→액션아이템
  (담당·기한→이슈 승격)·전문검색·첨부. 공지: 상단고정·대상·읽음확인. 결재선(선택).
- AC: 회의록 CRUD·결정→액션(이슈연결)·검색, 공지 읽음확인. 단순 목록 탈피.

### ⑦-b 공사일보 — 엑셀 양식 입출력 (대표 실무 대체 예시 ★)
- 목표: **회사 엑셀 양식 1회 등록 → 화면에서 작성 → 그 양식 그대로 엑셀/PDF 추출 + 리비전 + 결재선 + 모바일/사진.**
- 구현:
  1) **양식 등록**: 관리자가 .xlsx 템플릿 업로드, 셀↔필드 매핑(명명 셀 또는 {{placeholder}}·표 반복 영역 지정).
  2) **작성 폼**: 일자·인력·장비·날씨·작업내용(행 반복)·특이사항·사진. 모바일/오프라인(PWA) 작성.
  3) **엑셀/PDF 추출**: exceljs로 템플릿을 읽어 값 주입(스타일·병합셀 보존) → **양식 그대로** .xlsx 다운로드 + PDF.
  4) **리비전**: 일보 버전 이력·변경 비교·복원. **결재선**: 작성→검토→승인 + 서명/도장란.
  5) 사진 GPS·시간 자동 태깅. (선택) 음성→텍스트.
- 데이터: daily_log(有 확장)·daily_log_revision·log_template(project_id, xlsx, cell_map jsonb)·approval. RLS 쓰기=is_editor.
- AC: 양식 등록→작성→**등록한 양식과 동일한 엑셀** 추출·PDF·리비전·결재선·모바일 사진이 동작.
  (= "이래야 써먹는다": 기존 엑셀 방식 완전 대체.)
