# 샘플 공정표 (4D 타임라인 테스트용)

워크스페이스 하단 **4D 타임라인 → 공정표 임포트**에서 이 CSV들을 불러올 수 있습니다.

| 파일 | 출처 | 인코딩 | 비고 |
|---|---|---|---|
| `navisworks-timeliner-sample.csv` | Navisworks TimeLiner 내보내기 | UTF-8(원본은 EUC-KR) | 한글 헤더, 동기화 ID 보유. 21개 작업(2015-06~09) |
| `fuzor-timeliner-sample.csv` | Fuzor TimeLiner 내보내기 | UTF-8 | 영문 헤더, Fuzor GUID 보유. 발췌 59개 작업(2025-01~) |

## 사용법
1. IFC 모델을 연다(없어도 임포트·재생은 됨, 객체 제어만 비활성).
2. 하단 **공정표 임포트** → 위 CSV 선택. 파서가 포맷(Navisworks/Fuzor)을 자동 인식.
3. **순서 자동배정**(이름이 안 맞는 모델이어도 동작) 또는 **이름 매핑**으로 작업↔객체 연결.
4. 타임슬라이더를 옮기거나 **▶ 재생**으로 시공 진행을 확인.
   - 시공 완료=원래 색, 진행 중=주황 강조, 미시공=숨김(또는 "미시공 반투명" 체크 시 반투명).

## 포맷 메모
- 파서는 헤더 이름으로 컬럼을 찾습니다(`이름`/`Name`, `계획된 시작`/`Planned Start`,
  `계획된 끝`/`Planned End`, `작업 유형`/`Task Type`).
- Navisworks 한글 CSV는 EUC-KR(CP949) 인코딩이라 임포트 시 자동으로 EUC-KR 디코딩합니다.
- `OutlineNumber` 가 있으면 상위(합계) 작업은 시뮬레이션에서 제외합니다(Fuzor 루트 등).
